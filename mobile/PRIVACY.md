# ExpoCraft Mobile Privacy Checklist

Store release-д бөглөх minimum privacy disclosure.

- Account info: name, email, phone.
- Purchase/order data: cart, checkout, delivery address, order status.
- User content: product/order/custom request images uploaded by the user.
- Diagnostics: crash/runtime logs if an external monitoring SDK is added.
- Data is linked to account for marketplace operation.
- No sale of personal data.
- Camera/photos are optional and used only after user action.

Release өмнө:

- Apple App Privacy labels бөглөх.
- Google Play Data Safety form бөглөх.
- Privacy Policy URL: `https://expocraft.mn/privacy`.
- Support URL: `https://expocraft.mn/support` эсвэл бодит support email/domain.
